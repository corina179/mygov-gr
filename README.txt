MYGOV GR — DEMO PWA

Περιεχόμενα:
- index.html: η εφαρμογή
- manifest.webmanifest: ρυθμίσεις εγκατάστασης
- sw.js: offline cache
- icons/: εικονίδια εφαρμογής

ΕΓΚΑΤΑΣΤΑΣΗ ΣΕ IPHONE:
1. Ανέβασε ΟΛΟ τον φάκελο σε hosting που παρέχει HTTPS (π.χ. GitHub Pages).
2. Άνοιξε τη δημόσια HTTPS διεύθυνση στο Safari του iPhone.
3. Πάτησε Κοινή χρήση.
4. Επίλεξε «Προσθήκη στην οθόνη Αφετηρίας».
5. Πάτησε «Προσθήκη».

Σημείωση: Η εγκατάσταση PWA στο iPhone απαιτεί δημόσια HTTPS διεύθυνση.
Η εφαρμογή είναι ανεπίσημο demo και δεν συνδέεται με το gov.gr.
Δεν συλλέγει πραγματικά στοιχεία ή κωδικούς και δεν εκδίδει επίσημα έγγραφα.
